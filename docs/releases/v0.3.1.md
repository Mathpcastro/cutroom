# CutRoom 0.3.1 — seletores no estilo Codex

Prévia para Windows x64 com os controles de modelo e raciocínio refeitos conforme as referências do Codex.

- Cápsulas compactas no rodapé da conversa, com modelo e esforço em uma linha e botão circular para enviar.
- Menu de modelos com linhas simples, destaque arredondado e marca de seleção. Sem repetir os IDs técnicos ou ocupar espaço com uma caixa de busca; digitar com o menu aberto continua localizando modelos.
- Raciocínio em uma barra azul com marcadores, indicador branco, nome do nível e botão para restaurar o padrão. Os níveis disponíveis vêm do catálogo real de cada modelo.
- Suporte a mouse e teclado, fechamento por Escape e clique fora, e contraste ajustado para os seis temas.

Validação: 39 testes automatizados, revisão visual dos seis temas e testes no aplicativo Electron. Os sete modelos disponíveis na conta de teste foram verificados com seus níveis de esforço reais; uma conversa com o Codex confirmou o envio do modelo e do esforço selecionados.

Feche a versão anterior antes de executar o instalador. Projetos e o pacote de transcrição permanecem nos dados locais do aplicativo.
