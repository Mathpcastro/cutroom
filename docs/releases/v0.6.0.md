# CutRoom 0.6.0 — Sua IA, seu editor

O menu **Conversa → Conexão de IA** agora oferece Codex, Claude via terminal, Claude API, DeepSeek, OpenRouter e APIs compatíveis com OpenAI. Todas as opções usam as ferramentas de edição existentes, com streaming, progresso e cancelamento. As chaves ficam em memória durante a conexão.

Para Claude via terminal, instale a CLI oficial do Claude Code 2.1.248+ e faça `claude auth login` fora do CutRoom. O app reutiliza a configuração da CLI sem ler tokens. Sonnet, Opus e Haiku são aliases; disponibilidade e limites dependem da sua conta. APIs remotas exigem sua própria chave; serviços locais compatíveis, como Ollama, podem ser conectados por URL base e nome de um modelo que suporte ferramentas.

Validação: 106 testes passaram, build TypeScript/produção passou, revisão independente da interface em claro/escuro e três larguras sem erros. O app Electron foi exercitado com transporte HTTP local real, edição de projeto, desfazer, cancelamento, rejeição de URL insegura, conexão Codex existente e verificação da CLI Claude. O fluxo nativo da CLI + MCP leu e editou um projeto usando uma API de modelo local simulada. A chamada externa da CLI excedeu o prazo; APIs pagas não foram testadas com chaves reais de clientes. Veja [provedores e limites](../providers.md).

O editor continua gratuito; o uso de modelos remotos segue os custos/limites da sua conta. Transcrição e renderização ficam no computador. Texto e quadros solicitados podem ser enviados ao provedor escolhido.

Prévia para Windows x64. Sem atualização automática: feche o CutRoom antes de instalar. O instalador inicial não possui assinatura de código. Projetos e pacotes permanecem no perfil existente.
