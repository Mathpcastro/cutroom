## Regras para todas

- **Worktree:** `cutroom/worktrees/formatos`, branch `feat/formatos`. Enviar com `git push origin HEAD:feat/formatos` (o upstream local aponta para o repositório público de releases; nunca dar `git push` sem destino).
- **Compatibilidade:** não renomear `window.cutroom`, `appId`, `productName`, protocolos nem nomes de arquivos de dados. Só textos visíveis dizem "Videosell".
- **Uma implementação para UI e MCP:** toda ação nova da interface chama o mesmo serviço que a ferramenta MCP correspondente.
- **Textos:** português do Brasil por padrão, passando por `t()` (`src/components/studio/studioLanguage.ts`) com tradução em `studioTranslations.ts` (en, es). Sem "grátis" na interface.
- **Segredos:** chaves só no `SecretStore` (cifradas); nunca em log, renderer, snapshot ou resposta de ferramenta.
- **Publicação:** nada vai para o Instagram sem confirmação explícita do usuário para aquele vídeo, legenda, conta e horário.
- **Acessibilidade:** foco visível, navegação por teclado, `prefers-reduced-motion`, contraste AA nos dois temas.
- **Testes:** cada spec lista os seus. Rodar só os testes afetados durante o trabalho e a suíte completa uma vez no fim (`npx vitest run`; `avatar-creator.test.ts` pode estourar o tempo em paralelo e passa sozinho). Build: `npm run build`.
- **Verificação visual:** conferir cada tela no app real (`CUTROOM_USER_DATA=<pasta de teste> npx electron .` depois do build) em 1440 × 1000 e 1050 × 700, nos dois temas.
- **Registro:** ao fechar cada spec, atualizar o Obsidian em `Projetos/Videosell` (notas 20 e 22) com o que mudou e as evidências.
